# standard：工程规则

全项目统一遵守的工程规则，代码和文档按它评审。

## 写法

规则长期有效，修改要谨慎。规则与具体方案无关。

## 关系

其他文档通过 `governed_by` 指向它，表示受该规则约束。规则修订后，按规则复核合规。

## 例子

- 属于：编码规范、目录约定、文控规则。
- 不属于：某一个方案里的局部约定（→ design）。
