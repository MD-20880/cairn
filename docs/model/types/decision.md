# decision：决策记录（ADR）

一次重要技术取舍的记录：背景、决定和后果，用于长期解释"为什么这样做"。

## 写法

一份决策只回答一个问题。被新决策取代时，旧决策保留原文，由新决策声明 `supersedes`；部分修改时由新决策声明 `amends`。

## 关系

设计和规范通过 `governed_by` 指向它。决策被取代后，指向它的现行文档应当复审。

## 例子

- 属于：架构决策、方案选型、协议版本策略。
- 不属于：决策落地后的具体方案（→ design）。
